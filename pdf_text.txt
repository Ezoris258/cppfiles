哈希表
（Hash Table）
一种典型的“以空间换时间”的数据结构。
它通过散列函数，将大范围的键（Key）映射到有限的哈希桶（Bucket）中，从而实现期望时间复杂度为 O(1) 的查找与插入。
针对不可避免的哈希冲突，竞赛中通常采用基于静态链表的“拉链法”来解决，其底层代码结构与图论中的“链式前向星”完全同构。
const int MOD = 100003; // 取质数作为桶大小，减少冲突概率
const int N = 100005;
int head[MOD], nxt[N], key[N], val[N], tot;
void insert(int k, int v) {//插入键值对
int h = (k % MOD + MOD) % MOD; // 防负数取模
key[++tot] = k;
val[tot] = v;
nxt[tot] = head[h];
head[h] = tot;
}
int find(int k) {
int h = (k % MOD + MOD) % MOD;
for (int i = head[h]; i; i = nxt[i]) {
if (key[i] == k) return val[i];
}
return -1; // 未查找到目标
}
线段树
（Segment Tree）
线段树是分治思想在区间信息维护上的经典应用。
它将长度为 n 的序列递归二分，构建出一棵二叉树。
借助该形态，任意连续子区间 [l, r] 均可被拆分为 O(log n) 个不相交的树上节点区间，进而实现信息的快速合并（前提是所维护的信息满足结合
律，即构成幺半群 Monoid）。
配合“懒惰标记（Lazy Tag）”的延迟更新机制，线段树能以 O(log n) 的时间复杂度高效支持区间修改与区间查询。

const int N = 100005;
long long tree[N << 2], tag[N << 2]; // 4倍空间避免溢出
void pushup(int p) {
tree[p] = tree[p << 1] + tree[p << 1 | 1];
}
void addtag(int p, int l, int r, long long k) {
tag[p] += k;
tree[p] += k * (r - l + 1);
}
void pushdown(int p, int l, int r) {
if (!tag[p]) return;
int mid = (l + r) >> 1;
addtag(p << 1, l, mid, tag[p]);
addtag(p << 1 | 1, mid + 1, r, tag[p]);
tag[p] = 0;
}
void update(int p, int l, int r, int ql, int qr, long long k) {
if (ql <= l && r <= qr) { addtag(p, l, r, k); return; }
pushdown(p, l, r);
int mid = (l + r) >> 1;
if (ql <= mid) update(p << 1, l, mid, ql, qr, k);
if (qr > mid) update(p << 1 | 1, mid + 1, r, ql, qr, k);
pushup(p);
}
long long query(int p, int l, int r, int ql, int qr) {
if (ql <= l && r <= qr) return tree[p];
pushdown(p, l, r);
int mid = (l + r) >> 1;
long long res = 0;
if (ql <= mid) res += query(p << 1, l, mid, ql, qr);
if (qr > mid) res += query(p << 1 | 1, mid + 1, r, ql, qr);
return res;
}
Monoid
幺半群
一个代数系统要被称为 Monoid，需要满足以下三个要素：一个集合、一个满足结合律的二元运算、以及一个单位元。
懒标记的内涵
对当前节点，该节点自身维护的区间信息（如区间和、最值）已经是最新、正确的了。
对子孙节点的信息，目前都是过时的、未更新的。懒标记记录了本该下发给子节点的所有修改操作。
信息类型 节点维护的内容 合并方式 典型问题
求和 区间元素之和 sum = left.sum + right.sum 区间求和
最值 区间最大值、最小值 取左右子节点的 max 或 min 区间最大值查询
计数 满足条件的元素个数 左右计数相加 区间内有多少个正数
可合并的统计量 区间 GCD、按位 OR、AND 等 根据具体运算合并 区间 GCD 查询
复杂区间性质 最大子段和、最长合法子串等 维护多个辅助信息后合并 最大子段和查询
带懒更新的区间信息 区间和、区间最值等，加上延迟更新标记 更新节点信息并下传标记 区间加、区间赋值

哈希表. P1102 A-B 数对
概述题意
给定一个长度为 N 的正整数数列 a 和一个正整数 C，求满足 A − B = C 的数对 (i, j) 数量，其中 ai − aj = C 且 i = j。
1 ≤ N ≤ 2 × 105，数值及 C 均小于 230。
数学模型
设 f (x) 为数值 x 在数列中出现的频数。由 A − B = C 可得 B = A − C。遍历原数列，对每个元素 ai，与其配对的目标值为 ai − C，对应的
候选数量为 f (ai − C)。总方案数为：
ans = ∑i=1N f (ai − C)
解题思路
暴力枚举的时间复杂度为 O(N 2)。
使用哈希表（ unordered_map ）在读入数列的同时统计各数值的出现频次。由于数值范围较大且分布分散，哈希表能有效节约空间并提供高效的查
找。
再次遍历数列，对每个元素 ai 在哈希表中查询 ai − C 的频次并累加计入答案。
时间复杂度为 O(N )，空间复杂度为 O(N )。

#include <bits/stdc++.h>
using namespace std;
using ll = long long;
int main() {
ios::sync_with_stdio(false);

int n;
ll c;
cin >> n >> c;

cin >> a[i];
cnt[a[i]]++;
}
ll ans = 0;
for (int i = 0; i < n; i++) {
auto it = cnt.find(a[i] - c);
if (it != cnt.end()) {
ans += it->second;
}
}
cout << ans << "\n";
return 0;
}
cnt.find(a[i] - c)
使用 cnt[key]，如果键存在，则返回其对应的值的引用；
如果键不存在，它会自动在哈希表中插入一个新键，并将值初始化为默认值。
使用 cnt.find(...) 只进行纯粹的只读查找：若找到则返回对应迭代器，若不存在则返回 end()
本题坑点
合法数对的总数可能达到 O(N 2) 级别，int 会溢出，累加答案的变量使用 long long 。

建树：递归二分区间，叶节点存原数组值，非叶节点通过左右子树的区间和合并，时间复杂度 O(n)。
区间修改：当当前节点的区间完全包含于目标修改区间时，直接更新区间和与懒标记并返回；若仅部分包含，则先下传懒标记（ pushdown ），再递归
左右子树并重新合并。单次修改复杂度 O(log n)。
区间查询：完全包含时直接返回区间和；部分包含时先下传懒标记，再递归左右子树累加结果。单次查询复杂度 O(log n)。
整体时间复杂度 O(n + m log n)，空间复杂度 O(n)。

#include <bits/stdc++.h>
using namespace std;
using ll = long long;
const int MAXN = 100005;
int n, m;
ll a[MAXN];
ll sum[MAXN << 2], lazy[MAXN << 2];
void build(int p, int l, int r) {
if (l == r) {
sum[p] = a[l];
return;
}
int mid = (l + r) / 2;
build(p << 1, l, mid);
build(p << 1 | 1, mid + 1, r);
sum[p] = sum[p << 1] + sum[p << 1 | 1];
}
